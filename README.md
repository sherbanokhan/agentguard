# AgentGuard

**Zero-Trust Security for AI Agents and MCP Tools**

AgentGuard is a security engineering project that explores how autonomous AI agents can safely interact with third-party tools, APIs, files, and cloud resources.

The project combines AI security, product security, application security, and cloud security.

## The Problem

Modern AI agents can do more than generate text. They can interact with tools, access files, call APIs, execute workflows, and interact with cloud resources.

This creates new security risks when an agent has excessive permissions, receives malicious instructions, uses an untrusted third-party tool, or attempts an action outside the user's intended task.

AgentGuard explores how traditional security principles such as least privilege, authorization, supply-chain trust, and audit logging can be applied to AI agents.

## Project Goals

AgentGuard will:

1. Build a deliberately vulnerable AI-agent test environment.
2. Simulate AI-agent attacks in a controlled lab.
3. Analyze third-party MCP tools for security risks.
4. Assign trust and risk scores to tools.
5. Enforce runtime authorization before sensitive actions.
6. Implement task-scoped permissions and least privilege.
7. Protect sensitive data and secrets.
8. Record security decisions through audit logging.
9. Apply cloud-security controls using AWS.
10. Measure attack outcomes before and after security controls.
